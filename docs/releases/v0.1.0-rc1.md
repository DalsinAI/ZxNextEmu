# ZxNextEmu and ZX Cradle 0.1.0, release candidate 1

The first release candidate: a T-state-timed Spectrum Next emulator with
the classic Spectrums, the Russian clones, the SAM Coupé and the MSX, and
ZX Cradle, the browser machine manager and software library around it.

Tag: `v0.1.0-rc1`.

## Machines

- **Spectrum Next (TBBlue)**: boots NextZXOS to its menu from a host folder
  seen as a live FAT32 SD card. Built from the official FPGA sources: Z80N,
  memory, nextregs, ULA / LoRes / Timex / tilemap / layer 2 / sprites,
  copper, DMA, CTC, IM2, divMMC automap, three AYs, DACs, both UARTs,
  Kempston mouse, ESP8266 wifi and the Raspberry Pi (NextPi). (#1)
- **Classic Spectrums**: 48K, 128K, +2, +2A, +3, with contention, ULA video,
  floating bus, AY and beeper at the exact T-state; TAP, TZX, SNA, Z80. (#1)
- **Pentagon 128, Scorpion ZS-256, ATM Turbo 2+** with the Beta 128 disk
  (TR-DOS), a WD1793 timed to the byte; `.trd` written back, `.scl` read. (#12, #19)
- **SAM Coupé**: ROM 3.0, SAMDOS from disk, ASIC modes 1 to 4, SAA1099,
  two real-time VL1772 drives. (#10)
- **MSX1 and MSX2** (60 and 50 Hz): TMS9918 / V9938, slots, mappers, floppy
  and Sunrise IDE; Nextor boots from a host folder shown as FAT16. (#11, #14)
- **Spec256**: 256-colour games on eight shadow CPUs; all 29 games of the
  Spec256-Games collection with a snapshot run. (#7, #13)
- **ULA+** on every classic model, and the **MB03+ Ultimate / divMMC**
  interfaces: esxDOS, TurboSound, SAA1099, SID, General Sound, ZXi, the
  extra video modes, MBIDE and the RTC. (#6, #8, #24)
- Z80-only from now on: the Oric machines were taken out. (#21)

## ZX Cradle

- The browser page: every machine above except the Next, run by
  `zxcore.wasm` in a worker, with sound, keyboard, joystick, tapes, disks,
  snapshots and saved states kept in the browser. Controls laid out after
  AmigaChrome. (#2, #3, #5, #6, #16)
- Instances, recipes and ROMs, like Amiga Cradle's Cradle. Each instance
  now opens in a window of its own. (#16, #38)
- The software library: `title.json` per title, what runs on which machine,
  versions with language flags, ratings and reviews, companies and series,
  the same game on every system together, favourites, and screenshots and
  ratings per version. (#17, #18, #30, #33)
- `node host/host.mjs` (port 7080) serves the page and reads a library
  folder in place, plus the ROMs in `~/.zxcradle/roms`. (#27, #38)

## Tools

- `tools/zxcradle-fetch.sh`: one script that downloads the whole library
  (zxart.ee, vtrd.in, worldofsam.org, file-hunter, symbos.de, pouet.net,
  Spec256-Games, your OneDrive) to a local drive, and, new in this release,
  the ROMs the repository can't ship (TR-DOS, Scorpion, ATM Turbo 2+,
  esxDOS, General Sound), checked against their md5s. (#22, #23, #28, #29,
  #32, #35, #43)
- `tests/nextpi.sh` answers the new first-boot video-mode test card of Next
  firmware 1.46.
- `tools/msx`, `tools/onedrive`: library builders. (#20, #23)
- `tools/spec256bot`: the Spec256 auto-colouring bot, with its AI colouring
  step. (#25, #26, #31, #37)

## Tested for this candidate

On the tagged commit, Linux with GCC 13 (warnings on, none reported) and
clang 18 for the WebAssembly core, with the ROMs from
`zxcradle-fetch.sh "" roms`. Every suite passed:

| Suite | What it checks |
| --- | --- |
| `make test` | ZEXDOC and ZEXALL |
| `make sst` | SingleStepTests/z80, every opcode, T-states included: 0 failures |
| `make state` | all 15 machines, plus the MB03+ machines, save and load repeat exactly |
| `make wasmtest` | the same machines natively and in WebAssembly give identical pictures and sound |
| `make beta` | TR-DOS on the Pentagon, Scorpion and ATM Turbo 2+, and the disk images |
| `make esxdos`, `make mb03` | esxDOS 0.8.9 on four models; the MB03+ devices, General Sound included |
| `make sam`, `make ulaplus`, `make vfat`, `make esp` | SAMDOS save and load, SAA1099 pitch; ULA+; FAT32 and FAT16 folder cards; the ESP8266 wifi |
| `make nextpi` | NextZXOS's Pi tools, on the current Next software (firmware 1.46, NextZXOS 2.10a) and on the September 2026 one |
| `make desktop` | the SDL2 front end builds |

The live ZX Cradle page was rebuilt from this commit and checked at 770 and
1280 pixels wide, including an instance opening in its own window.

## Known gaps

- The Next doesn't run in the browser yet (it needs its SD card there).
- The +3 disk drive isn't emulated yet.
- Next: multiface and Pi audio are still to come; SAM: mouse and external
  memory.
- In the published page, the browser may block the window an instance opens
  in; allow pop-ups for the page.
- Built and tested here with Linux GCC; the AmigaOS build with GCC
  16.2.0-open3 hasn't been checked for this candidate.
